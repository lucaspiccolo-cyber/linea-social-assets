# linea-social-assets

Visuels **validés** des publications réseaux sociaux gérées par Linéa Studio, hébergés ici pour que
Metricool puisse les récupérer (adresses `raw.githubusercontent.com`).

- Alimenté automatiquement par `scripts/publish-assets.sh` du Content Engine.
- Uniquement des contenus au statut `approved`. Aucun brouillon, aucun fichier de travail.
- Arborescence : `<client>/<id-publication>/<visuel>.png`
